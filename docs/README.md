# Regression Scan Statistics for ALMA Platforming - GitHub Pages site

This folder contains a static GitHub Pages landing page for the RegressionScanStats project.

## Files

- `index.html` - project landing page
- `styles.css` - responsive styling

## Quick publish options

### Option A: Publish from an existing repository

1. Copy `index.html` and `styles.css` into the root of your repository, or into a `docs/` folder.
2. Commit and push.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch and folder you used, such as `main / root` or `main / docs`.
6. Save. GitHub will give you a public URL after the build completes.

### Option B: Create a separate project page repository

1. Create a repository, for example `RegressionScanStats-page`.
2. Add these files.
3. Enable GitHub Pages from **Settings > Pages**.
4. Link the page back to the code base: https://github.com/BeardyMan37/RegressionScanStats
