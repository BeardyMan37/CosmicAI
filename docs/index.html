General-purpose interval anomaly detection

Scan statistics for smooth signals.

A general scan-statistics tool for finding compact anomalous intervals in spectra, time series, and other smoothly varying signals. It keeps the background model interpretable, returns an auditable interval, and scales to QA workflows.

What it does

Fit smooth backgrounds, score candidate intervals, and return the strongest anomaly.

The method compares a single smooth fit against separate inside/outside fits for each candidate interval. A large score means separating one interval explains the signal much better than forcing a single background model.

S(Ia,b) = 1 - (SSEin(Ia,b) + SSEout(Ia,b)) / SSEall

That score is then maximized over intervals to produce an auditable flag.

Application

ALMA platforming is one concrete use case.

ALMA QA2 platforming

Calibration spectra are smooth but not flat. Platforming is a compact instrumental offset that can propagate into science cubes if it is not flagged early.

  • Localized interval anomaly in frequency space
  • Returns a row score, interval, and fitted background
  • Designed for review-friendly QA2 screening
